다크모드 방지 (필수)
중요: 이 디자인은 아이보리 배경을 핵심 요소로 사용하므로, 사용자의 OS 다크모드 설정에 영향받지 않도록 반드시 아래 코드를 적용해야 합니다.
<!-- HTML head에 추가 --> <meta name="color-scheme" content="light"> /* CSS */ :root { color-scheme: light; } html { background: #f0ede5; color-scheme: light; } body { background: #f0ede5; color: #1c3254; color-scheme: light; } input, select, textarea { color-scheme: light; }
새 웹페이지에 적용하는 방법

① 시스템 색 1개 지정 — 해당 페이지의 기능을 대표하는 색을 정해 --sys 변수에 할당
   예) 인원계수 → 주황 계열, 장소예약 → 인디고 계열, 행사 신청서 → EXR 초록

② :root 변수 복사 — 위 CSS 변수 블록을 그대로 사용

③ 헤더 구조 적용 — 네이비 배경 + 골드 하단 바 + 시스템 세로바

④ 카드 컴포넌트 사용 — 흰색 카드 + 시스템색 카드 헤더 + 번호 원

⑤ 버튼/폼 스타일 적용 — 위 코드 그대로 복사

⑥ 다크모드 방지 — meta 태그 + color-scheme:light 필수
